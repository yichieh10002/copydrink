- 得正：營養基準為全糖去冰最高值；奶蓋為全糖少冰；熱飲熱量未知。

## 後續資料需求

- 各店的更新日期、分店／地區價格差異。
- 得正的實際甜度與冰量級距、WUWIN 容量與杯型。
- 各品項配料相容性、是否可換奶及加價。
- 飲品描述、成分與奶類標示；不可僅憑品名推定奶精、鮮奶或混合比例。
- 不同溫度的價格與營養差異；目前菜單同價格欄下的溫熱選項保留相同列價，營養不延伸。
