# 菜單工作室新版：開發與回退

更新：2026-11-17。**目前僅在本機分支，沒有推送、部署或更動 Supabase 資料。**

## 安全的切換方式

- 原版後台仍在 `dist/admin.html`，沒有修改；現有 Sites 靜態站和 Vercel 預覽仍使用先前的來源。
- 開發分支 `feature/admin-workspace-v2`；開始前的程式標記 `admin-v1-before-rebuild-20261117`（指向 `fdd97ad`）。新版在 `frontend/src/app/(admin)/admin`，路徑 `/admin`。
- 前台頁面搬進路由群組 `(site)`，原網址 `/` 和 `/stores/[slug]` 不變；獨立根 layout 讓 Tailwind 只載入新版後台。現有 `dist/` 與 Supabase schema 不變。
- 若版面出錯，停用新版 `/admin` 的路由即可回到原後台；若已部署則回退前一個 Vercel 部署。資料與發布不能只靠程式部署回退，發布前應先匯出草稿並保留發布紀錄。

## 已做

- 管理者登入（JWT 僅在頁面記憶體）、權限查核、登出、店家清單、建立店家草稿。
- 飲料搜尋、分類篩選、菜單順序／最新加入／依分類／依品名檢視；手動上移下移會儲存至草稿。舊資料沒有建立時間，最新排序以原陣列順序推估。
- 飲料新增／複製／編輯／刪除、批次上架／下架／刪除、杯型和地區價格、標籤、長文欄位自動長高、必填與錯誤標示、儲存並新增下一杯。
- 分類、活動、必喝 TOP、店家設定（基本網址、品牌介紹、Logo 圖片匯入、甜度／冰量／配料、杯型、地區）、溫熱飲提醒的編輯。
- 單杯客製可沿用／隱藏／固定／限制店家選項，新增專屬客製群組，設定熱飲杯型與加價、特殊杯型出現條件。
- 成功／失敗 toast、未儲存切換提醒、草稿匯出、發布前摘要預覽、版本發布與還原。登入、側邊欄、店家列表與確認視窗已從工作區主元件拆開。
- 現有前台頁面不改功能。建置、TypeScript、13 項前台與新後台模型測試、樣式檢查、格式檢查均通過。

## 切換前仍要做

1. 以舊後台的實際特殊客製資料逐一比對新版輸入、固定值、熱飲專屬杯型與加價；補進階地區價格複製，以及溫熱飲提醒的發布歷史還原。
2. 對店家設定與飲料編輯的長表單繼續拆分，實測鍵盤操作與編輯效率。
3. 使用真實的既有草稿做只讀比對；用隔離的測試店家驗證新建、儲存、重新登入、發布、前台顯示及還原。不以正式菜單做測試寫入。
4. 完成 `database/harden-publications.sql` 的私有欄位隔離並驗證後，再讓新版發布含 `source`／`internalNote` 的草稿。現在線上公開快照仍有私有欄位鍵，**不能宣稱安全問題已解決**。
5. 檢查手機及桌面實際操作和鍵盤可及性，再決定切換入口。沒有切換前保留原版後台。
