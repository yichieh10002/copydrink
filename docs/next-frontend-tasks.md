# 前台 Next.js 重構任務

新前台放在 `frontend/`；現行 `dist/` 與後台發布流程維持原狀。此清單是重構工作追蹤，不代表新版已可上線。開發預覽會休眠或停止，不能作為驗收連結。

## Task 1 — 專案骨架與資料邊界

- [x] 建立 Next.js App Router、TypeScript 與獨立前台目錄。
- [x] 以既有 Supabase 已發布快照作為唯一雲端正式資料來源，隔離資料存取與轉換。
- [x] 雲端讀取失敗時顯示可重試的錯誤畫面，避免以過期內建菜單冒充最新資料。

## Task 2 — 可索引頁面與共用畫面

- [x] 首頁和每家店的固定網址、舊 `?brand=` 入口相容。
- [x] 店家資訊、分類、地區價格與飲料列表拆成元件。
- [x] 各店 metadata、canonical（需設定正式網址）、sitemap、robots 與 404。
- [ ] 分享圖與社群預覽；在正式網址與部署環境確定後驗證。
- [x] 首頁接回既有插畫、店家卡數量與必喝 TOP 黃色標籤；手機店家資料預設收起，讓菜單先出現。
- [ ] 對照舊站做 360／768／1440 的視覺修整，尤其深色模式與店家卡密度。

## Task 3 — 客製和複製

- [x] 飲料彈窗、杯型／甜度／溫度／配料等選項、熱飲加價與限定杯型的基本流程。
- [x] 複製文字、資料庫與一般填寫筆記、價格勾選、署名／店家順序按鈕與重設；資料庫飲料也保留自行輸入欄位。
- [ ] 比對舊版所有選項規則、固定值、加價、複製格式；評估是否仍需觸控拖曳（目前手機用上／下移按鈕）。
- [x] 店家與飲料名稱搜尋及飲料直接進入連結。
- [ ] 驗證輸入法組字、鍵盤操作、注音別名、最近查過等舊版細節。
