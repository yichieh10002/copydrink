# 菜單工作室 v0.10

入口：`/admin.html`。這是可以操作的前端流程原型，不是正式管理後台。

## 已實作

- 店家列表、搜尋、只看有變更；建立店家。
- 得正 24 杯／WUWIN 64 杯的原始資料初始化。
- 商品新增／編輯／複製（品名清空、下架預設）、杯型列、參考價格、熱量基準、點餐文字提醒、推薦、所屬活動、內部來源／備註。
- 儲存並新增下一杯；離開未儲存表單提醒；批次上下架。
- 限定活動與整組上下架；店家共用選項和提醒。
- 每家店獨立草稿、變更清單、預覽、模擬發布快照、歷史預覽／載入為草稿後重新發布。
- JSON 匯出包含草稿、模擬發布快照、歷史；尚無匯入介面。
- UI 以 textContent 呈現管理者輸入。留空價格／熱量維持 null，零值維持 0。

## 儲存與權限界線

只使用 localStorage `tea-admin-prototype-v1`。無登入頁，無伺服器寫入、無雲端資料庫；同一瀏覽器可修改此測試資料。現有 Site 的 owner-private 存取設定維持不變。

「模擬發布」只更新管理頁面的本機快照；`index.html` 仍使用原來的檔案資料，其他訪客不會讀到這些變更。預覽是管理頁內的前台內容示意，尚未共用查詢頁渲染器，也不包含客製／複製操作。

清除瀏覽器網站資料會清除草稿，請使用匯出備份。容量不足時呈現儲存錯誤，不宣稱成功。

## 下一個正式串接範圍

1. 依託管平台選擇伺服器執行環境與持久儲存，先確認管理者身分與允許名單；公開使用者不需要登入。
2. 所有寫入、預覽草稿、還原操作由伺服器驗證權限與欄位，不信任前端按鈕或網址隱藏。
3. 以店家為發布單位；交易中建立不可變快照、切換 published revision；以 revision 防止同時編輯覆蓋。
4. 前台只讀已發布快照、按店家載入與快取，篩選與複製仍在裝置處理。草稿來源與公開回應分離。
5. 接入前台共同資料模型，保留原始來源與營養基準，正式發布不重新部署網站。
6. 備份還原、稽核紀錄、伺服器整合／權限測試後再開放正式維護。

尚未實作：雲端保存、認證授權、正式 API、多人同步、排程上下架、地區菜單版本與拖曳排序。未作容量或並發承載保證。
