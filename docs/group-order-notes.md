# 團訂使用情境

使用者先選好店家（例如 NAP TEA），再將店家完整菜單連結傳給跟團的人。

已實作：
- URL 的 brand 參數還原指定店家；重新開啟時不套用本機已保存的篩選，顯示該店完整菜單。
- 店家資訊卡提供「複製店家連結」。
- 跟團文字可選擇是否帶入店名；署名與手填價格只有有填才顯示。

後續：
- 原型目前仍為私人存取；正式分享給朋友前，由使用者決定公開或指定存取對象。
- 換成經確認的完整店家菜單、容量、價格及口味限制。
- 單杯複製不代表下單或團單彙整。

## 首頁自填小抄與溫熱提醒（2026/10/19）

- 首頁入口可開啟自由填寫彈窗，不讀取店家菜單或儲存成店家資料。
- 店家、品名、甜度、冰量／溫熱、數量必填；署名、杯型、換奶、配料、價格、備註選填。
- 店名是否帶入複製文字可勾選；空白配料、價格與備註省略。
- 品名含冰沙等關鍵字且選溫熱時只提示，不阻擋複製，不試圖驗證所有店家規則。
- 表單草稿只保留在此次頁面記憶體，不持久保存，也不新增搜尋紀錄。
- 溫熱飲提醒以卡片列出標題、備註、資料狀態與來源。得正／龜記為報導佐證，一沐日為特定官方門市資料，茶湯會為特定門市外送菜單。大茗／迷客夏尚待確認。
- 得正 2026/9/1 生效日期未取得直接官方佐證；不寫成已證實的公告，也不將補足茶奶量解釋歸因官方。
- 提醒資訊與上傳菜單快照分開：原菜單的歷史價格不自動覆寫，使用者請以現場最新價格為準。
- 手機回頂部按鈕滑動超過 280px 才出現，到頂部或開啟彈窗時隱藏；半透明且尊重減少動態效果設定。

## 提醒與店家資訊調整（2026/10/19）

- 依使用者提供文字更新溫熱飲提醒：得正溫／熱 +5，大茗熱飲中杯 600ml，再睡五分鐘熱飲中杯約 480ml，有飲溫熱中杯 500ml，茶太溫熱中杯 16oz；茶湯會重複條目合併，保留特定門市資訊的適用範圍說明。
- 新增內容為使用者提供的顯示文字，本次未另行查證，也不連動選項或計算價格。
- 溫熱飲卡片移除「待確認／官方門市資料／報導佐證」等狀態標籤，保留既有來源連結與適用範圍文字。
- 所有彈窗的關閉按鈕改為「× 關閉」，輔助標籤「關閉視窗」。
- 店家標頭移除「店家資訊」標籤與說明句；得正新增店家資料區，官方網站／菜單／門市資訊僅作停用展示，沒有超連結。
- 推薦區預設收合，點標題再展開。

## 複製表單與卡片版面（2026/10/19）

- 首頁不顯示上一頁按鈕，即使瀏覽歷史還有站內步驟；店家或搜尋結果頁仍可返回。
- 自填與品項小抄共用固定頂部區：關閉、文字預覽及複製按鈕固定，下方表單獨立捲動。按鈕以 form 屬性維持原生表單必填驗證。
- 署名移至備註之前，複製文字仍把署名放在開頭。
- 自填店家欄提供已收錄店家建議，也允許任意店家名稱。非空白後啟用其餘欄位，清空店家即再次停用；已填欄位不因清空店家而遺失。
- 店家選好後顯示官方網站／菜單／門市資訊小卡；目前仍是無連結展示，所有已收錄店家皆使用相同小卡。
- 品項小抄依先前確認的新方向，甜度與冰量／溫熱一律提供通用選項，原固定限制改顯示點餐提醒，不攔截複製；參考價不保證符合客製後價格。
- 顯示方式改名「精簡」「詳細」。詳細卡片順序為店家分類、品名與收合、價格、既有備註、點列點餐提醒與熱量，推薦另保留標示；沒有實際備註時不填假內文。
