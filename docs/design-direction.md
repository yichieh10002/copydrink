# copydrink design direction

Updated 2026-11-01.

- Primary brand blue: #2A5290; warm white and elegant serif titles.
- Home: large full-width colour fields, generous whitespace, curved section joins, illustration crossing section boundaries. Avoid repeating rounded feature cards everywhere.
- Preserve outlined menu category containers and compact menu interaction. Category names render exactly as entered; no automatic suffix.
- Footer: a large brand slogan, smaller store-authoritative price/supply reminder, and self-fill entrypoint.
- Keep light/dark mode, all existing search/copy flows, admin and backend data intact.
- Motion is a later discussion; the current change establishes the static composition.
